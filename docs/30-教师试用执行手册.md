## 1. 🔴 起服务：三个参数缺一不可（最易踩坑）

```bash
cd C:\Users\41271\WorkBuddy\2026-09-19-15-04-23\scheduler
python scripts/run_server.py --port 8000 --today 2026-10-12 --db data/trial.db
```

| 参数 | 🔴 不带会怎样 | 为什么 |
|---|---|---|
| `--db data/trial.db` | 连到 `demo.db` → **没有 trial 账号 → 登录必失败** | 试用数据在独立库里 |
| `--today 2026-10-12` | 🔴 **冲突数 = 0**，页面显示「没有冲突」 | 学期起点锚定该日期所在周周一 |
| `--port 8000` | 用默认 8000 也能起| 只是显式写出来，避免与别的服务撞端口 |

> 🔴 **`--today` 用错是本次实测发现的第 11 处静默失效**：
> 用 `--today 2026-09-08`（文档里原来写的演示日期）→ **0 冲突，且页面不报错**。
> 老师会以为系统坏了，或根本不会去点「一键消解」→ **采不到完成率**。
> **2026-10-08 已修**：`build_trial_org.py` 的 `TERM_START` 改为 `2026-10-12`。

**✅ 起对了的标志**（READY 行应包含）：

```
READY host=127.0.0.1 port=8000 db=...\data\trial.db today=2026-10-12
```

## 3. 现场流程（每人一循环）

| 步 | 动作 | 要点 |
|---|---|---|
| **1** | **发编号** | 当面给 `T01`…`T15`。🔴 **建议打印小纸条**（口头易记错，`trial_code` 回收失败就废了这个人的数据） |
| **2** | 登录 | 账号 `trial_t01`…`trial_t12`，密码见 `build_trial_org.py:69` |
| **3** | 输入编号 | 首次使用时输入自己的 `T__`，前端记住 |
| **4** | 正常用 | 看课表 → 查冲突（应见 32 处）→ 一键消解 → 观察是否真的解决 |
| **5** | 🔴 **当场收纸质问卷** | 回收率最高；**纸质原件是真实性物证，答辩可展示** |
| **6** | 记映射 | 编号→姓名**只写纸质本** |

### 🔴 不要做的事

| 禁 | 原因 |
|---|---|
| 用真实学生课表做演示 | 红线 1 |
| 让老师用**自己的真实课表**导入 | 同上 |
| 把纸质问卷原件拍照传公网 | 含姓名，破匿名 |
| 只让老师「围观」不让他操作 | 🔴 没操作 → `task_start` 为 0 → **不计入试用人数** |

## 4. 🔴 问卷（6 题，现场当场填）

> ⚠️ **不要用「整体满意度 1–5 分」当核心题**（`docs/08 §4.2`）：
> 中学教师碍于情面普遍打 4–5 分 → 拿到的是**礼貌性高分**，评委一问就穿帮。

**你的编号（T__）：__________日期：____**

| # | 题 | 答 |
|---|---|---|
| 1 | 如果下周还要排一次，你愿意用这个系统代替现在的方式吗？ | 愿意 / 不确定 / 不愿意 |
| 2 | 你会主动向同组老师推荐它吗？ | 会 / 不确定 / 不会 |
| 3 | 「一键消解」给出的方案，你实际采用了几个？ | 0 / 1 / 2 / 3 |
| 4 | 操作是否顺畅（不用人教就会用） | 1 2 3 4 5 |
| 5 | 你最想吐槽的一个功能点是： | __________ |
| 6 | 最想改进的一点： | __________ |

**报告时必须给分布**（n、均值、标准差、1–5 各档人数、开放题摘录），不能只给均值。
🔴 **样本 15 人时不报百分比**，改报绝对数：「15 人中 12 人愿意继续使用」。

## 5. 🔴 现场话术（被问到时照说）

> 「系统内置埋点：教师用一次性编号登录，系统记录任务发起、成功、放弃三类事件，
> 按编号去重统计人数、按 5 分钟断线规则剔除挂机时长；试用结束后另收纸质问卷。
> 数据只出聚合数，编号与姓名的对应关系保存在纸质记录里，从不进入系统。」

**若评委问「为什么试用从 10/12 开始」**（原计划 10/8）：

> 「前端埋点没接完就试用，采集不到数据反而是自欺。延期到 10/12 后，
> 后端采集链路已实测跑通，四类数据都能产出——**宁可晚几天采真数据，也不做无效试用**。」
