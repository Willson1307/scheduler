## 1. 四档权限：机制不变，语义重定义

| 档 | `level` 值 | 能做什么 |
|---|---|---|
| 查看 | `view` | 登录后至少能看（人人都有） |
| 提出 | `propose` | 提交改动**请求**，自己不能直接改 |
| 批准 | `approve` | 批准 / 拒绝**自己下级**提出的请求 |
| 拥有 | `own` | 修改组成员与结构；批准**永久类**请求 |

**四条机制原样保留**（不要动）：
1. 沿对象图祖先链继承
2. 多条路径取**最高档**
3. 全局角色当**天花板**
4. 不做"负权限 deny"（多父 DAG 下语义不自洽）

列名仍用 `level`（`GRANT` 是 SQL 保留字）。

> ⚠️ 与上版唯一的区别：原来的 **edit / manage 不再代表"能直接改"**，改成了"能提请求 / 能批请求"。
> 这是整个审批流的基础——**任何人都不直接改数据**。

---

## 2. 什么要审批，什么不要（🔴 这张表是核心）

| 改动 | 影响面 | 审批？ | 归类 |
|---|---|---|---|
| 本周临时调课 / 取消（`schedule_exceptions`） | 本周一次 | ❌ 直接生效，可撤销 | 单次改 |
| 一次性活动改期 / 取消 | 单次 | ❌ 直接生效，自动通知受影响的人 | 单次改 |
| 周期课表改节次（整个学期跟着变） | 长期 | ✅ **要批** | 永久改 |
| 新增 / 删除周期日程 | 长期 | ✅ **要批** | 永久改 |
| 修改组成员、建组 / 删组 | 长期 | ✅ **要批** | 永久改 |

**判据一句话：改一次不用批，改规则或改长期安排要批。**

> 为什么要这么分（答辩要能讲）：
> 单次改的风险局限在一天之内，撤销成本低，要求审批会拖慢日常使用；
> 永久改会改变整个学期的安排，影响所有相关师生，必须有人复核。

## 3. 请求状态机

```
draft ──提交──▶ pending ──批准──▶ approved ──落库──▶ applied
                  │
                  ├──拒绝──▶ rejected
                  └──撤回──▶ withdrawn（提出人随时可撤）
```

规则：
- 提出人可随时撤回自己的 `pending` 请求
- `pending` 超过 24 小时 → **提醒批准人一次**（不自动通过，见 §8 待确认）
- **只有 `approved` 才由系统自动落库**，不允许人工去执行
- 落库失败 → 回滚请求状态并报错，不留半改状态

## 5. 试用期的执行口径（🔴 最容易翻车的一节）

批准人由**相关领导真实担任**（队长指定）。配套要求：

| 项 | 要求 | 归属 |
|---|---|---|
| 集中审批 | 领导每天固定时间集中批一次（具体时间**待确认**） | 队长 |
| 审批页 | 一屏内看完"改了什么"，两个按钮（同意 / 拒绝），**必须手机可用** | 独此一嘉 |
| 超时提醒 | `pending` 超 24h 提醒批准人 | 独此一嘉 |
| 我的请求 | 老师能看到自己提的请求到哪一步了 | 独此一嘉 |

**🔴 任务完成率必须按类分开统计，不能合成一个数**（否则数据会失真）：

| 任务类型 | "完成"的定义 |
|---|---|
| 单次改（临时调课、活动改期） | 成功应用（自动生效，不需等待） |
| 永久改（调课、改组） | 请求到达**终态**（approved / rejected）才算；**pending 不算完成** |
| 查看冲突 | 打开冲突列表 |

四类原始数据（试用人数 / 平均使用时长 / 任务完成率 / 满意度）**按上述口径分别汇报**。

> ⚠️ **风险提示**：如果领导响应不及时，永久改类的完成率会很难看。
> 缓解办法：试用时的主推任务是**单次改**（自动生效、不卡审核），永久改作为进阶演示。

## 6. 🔴 学生：存储逐个、权限按类（别搞反）

| 侧 | 做法 | 为什么 |
|---|---|---|
| **存储** | 每个学生一个 `objects` 行（1500 个照存） | 冲突检测要算"**这个学生个人**"是否撞课——社团活动 vs 他本人的课。**砍掉这项，系统就瞎了一半** |
| **权限 / 账号** | 学生没有 `users` 行、不登录，所以不存在"给每个学生配权限" | 学校不给初高中生个人账号；"按类"**仅限权限侧** |

一句话：**存储逐个、权限没有**。这两句同时成立，不矛盾。
