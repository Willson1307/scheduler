## 1. 🔴 最贵的事故：`--today` 不加，材料与实物不符

### 1.1 现象

| 启动方式 | 网页/接口显示的冲突数 | 报名材料写的冲突数 | 结论 |
|---|---|---|---|
| `python scripts/run_server.py`（**不加分句**） | **1 处** | 23 处 | 🔴 **当场翻车**：评委看着「23 处冲突」的材料，页面上只有 1 处 |
| `python scripts/run_server.py --today 2026-09-08` | **23 处** | 23 处 | ✅ 一致 |

### 1.2 根因（已定位到行）

- `src/server/api_resolve.py:115` 的 `_resolve_window(cfg)`：消解接口的**扫描窗口 = `cfg.today` 所在周（周一~周日）**。这是 `docs/07 §4` 定的「本周」语义，**本身没错**。
  （该文件在 B4 分支 `feat/server-api` 上，commit `2fe61b0`；行号以该commit 为准。）
- 演示库的学期起点是**固定**的 `2026-09-07`（`scripts/reset_demo.py:34` `TERM_START`），**全部 23 处冲突都密集排在这一周**（第 2/3/4 周各只有 1 处）。
- 不传 `--today` 时 `cfg.today = date.today()`。**10-04 当天 → 窗口 = 09-28~10-04 → 只覆盖 1 处冲突。**
- ⚠️ **这个坑会随日期漂移**：越往后拖，`cfg.today` 离09-07 越远，窗口越扫不到东西。**现场当天（10-23）不加分句，连 1 处都可能扫不到。**

> 10-04 实测（扫 `data/demo.db`，非推断）：
> ```
> 第1周 09-07~09-13  <- --today 2026-09-07 / 09-08  -> 23 处
> 第2周 09-14~09-20                                ->  1 处
> 第3周 09-21~09-27                                ->  1 处
> 第4周 09-28~10-04  <- 今天 10-04 所在周->  1 处
> ```

### 1.3 铁律

**每次启动服务端，命令里必须带 `--today 2026-09-08`。**

- 为什么是 `09-08` 而不是 `09-07`：`monday_of()` 取该日期所在周的周一，`09-07`/`09-08` 同在第 1 周内，效果逐字相同。选 `09-08` 是因为与已实测复现 `23→0` 的那次命令完全一致。
- **不许临场想「今天几号」。** 抄 §3.1 的命令，别改日期。

## 附：为什么 23 这个数可以放心讲

`scripts/reset_demo.py` 的固定种子参数（`classes=3, students_per_class=10, teachers=9, rooms=4, term_start=2026-09-07`）+ 固定种子随机源→ **每次重置出来的冲突数（23）、对象数（48）逐字一致**。
