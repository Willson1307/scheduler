```
本项目为参加嘉祥锦江中学少年科学院第一届"脑洞上线"AI创意设计挑战赛的参赛作品开发。

【目标】用MVP思路开发一个以AI实质解决真实校园/生活问题的网页作品：核心功能少而精、现场演示绝对稳定、AI内核清晰可讲解。评审权重：工程实现30%、创意选题25%、应用与社会价值25%、展示与答辩20%。

🆕【选题与当前状态】
- 项目名：课表活动撞车难调，AI求解一键消解；仓库名：scheduler（不叫 school-scheduler，模型不绑定学校场景，便于后续拓展）。
- 一句话：把课表（长期重复事务）与活动（一次性事务）归一到同一套时间占用模型上，用自建的 AI 约束求解器做统一冲突检测、自动排布与最小改动消解。
- 已完成：B0 数据层（对象图 DAG+闭包表、节次与位图、统一占用与冲突检测）、B4 AI 内核（硬/软约束引擎 + M2 冲突消解，一键消解实测 23 处冲突→0）。31 项单元测试全绿，零第三方依赖，断网可跑。
- 技术栈：Python 标准库 + SQLite，不引入 Web 框架，保证现场断网可跑；领域层全部写成与框架无关的纯函数，将来要换 FastAPI 只需替换一层薄适配。
- 四条硬性设计约定（改动前先确认）：
  1. 对象 ≠ 账号：objects 可全量存 1500 名学生（调度与冲突检测用），users 只放真正要登录的人；
  2. 位图是加速层不是真相层：真相是 period_slots 配置 + 周期规则 + 起止时刻；
  3. 课表与活动共享底层：都归一化为「(日期, 当天槽位掩码)」，冲突检测只有一套位运算，排课因此看得见已安排的活动；
  4. 求解器负责算，大模型只负责听懂人话与选模式；求解环节不调用任何大模型接口。

🆕【当前阶段约束】先搭基础框架，不往深处动工
- 原则：先打通一条能从头跑到尾的细线（启动 → 打开页面 → 看到冲突 → 一键消解），每一层先做到"能通"，深度留到闭环跑通之后再补。
- 暂缓（未跑通闭环前不要碰）：M1 全局排课、M3 局部补排、偏好权重学习、拖拽排课、CSV 批量导入 1500 人。
- 深浅边界见仓库内 docs/02-基础框架边界.md，新增功能前先对照该文件判断属于哪一层。

【团队】3人小队：A=队长（任务分配+审核），B和C分工灵活，按任务卡认领开发、内容、数据、测试工作。

【协作规范】
1. 源码以GitHub仓库为准：功能改动走feature分支+PR，PR描述需注明对应任务和AI生成部分；
2. 本地代码操作（clone/commit/push）直接执行git命令；PR创建、Issue管理使用GitHub连接器；🆕（注：当前环境未安装 GitHub 连接器，插件市场只有 CNB，暂时改用 gh CLI 或在网页手动建 PR/Issue；连接器可用后再切回）
3. 涉及核心功能开发的大任务，提醒用户可召唤MVP开发专家团（专家中心召唤）；
4. AI生成的代码必须说明用途与设计意图，便于队员理解和答辩；
5. 产出用中文，优先结构化表格；重要结论沉淀到项目资料库。

【工具调度】
6. 开发页面/组件时使用frontend-design技能保证界面质量；制作三折展板（1220×900mm）时使用canvas-design技能；进入试用阶段时主动提醒用户用"发布为应用"将作品发布为公开链接，供真实用户访问采集数据；🆕（注：发布上线时只能用脱敏的"试用组织"数据——真实学生名单与课表按学校规定不得出校、不得上公网）
7. 生成Word项目书用tencent-docx，演示PPT用tencent-pptx，数据统计表用excel-generation，章程等材料用pdf。

【关键节点】
- 9月30日前：完成电子项目书并提交报名（硬截止，需指导教师签字）
- 🆕10月7日24:00：系统必须达到"可给教师试用"状态（国庆假期人在校外收不到真实体验数据，10/8 开学到 10/23 现场只剩约 10 天试用窗口且无缓冲）
- 10月上旬：启动真实用户试用（需作品已发布上线），采集人数/时长/完成率/满意度数据
- 10月23日：现场评选，5分钟演示+5分钟答辩

【章程硬性约束（源自章程，务必遵守）】
- 组队2-3人，报名截止9/30须提交电子项目书，截止后原则上不得换人；
- 现场评选10/23：纸质项目书+三折展板（1220×900mm，折页300/300，主面620mm）+5分钟演示+5分钟答辩；
- 评审权重：工程与技术实现30%、创意与选题25%、应用与社会价值25%、展示与答辩20%；
- AI须实质性解决核心问题，作品须有真实用户体验数据，组委会核查源代码验证原创性。

完整章程已存于项目资料库"嘉祥锦江中学少年科学院第一届“脑洞上线”AI创意设计挑战赛-章程"文档，涉及具体条款细节时先查阅该文档再作答。
```
