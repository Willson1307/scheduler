### 5.1 🔴 docs/17 §7.2 冒烟 curl 已过时（现场照抄必 401）

docs/17 §7.2 给的冒烟命令**不带 token**：

```bash
curl -s -X POST "http://127.0.0.1:8000/api/resolve" -d '{"org":"试用学校","mode":"m2"}'
```

实测现在返回：

```
{"error": {"code": "unauthorized", "message": "未登录或令牌无效"}}
HTTP 401
```

`GET /api/conflicts` 不带 token 同样 401。**B3 鉴权后这两个接口都要先 login 拿 token。** 现场照抄旧命令会拿到 401，被误判为「接口坏了」。

**正确写法（现场用）**：

```bash
TOKEN=$(curl -s -X POST http://127.0.0.1:8000/api/login \
  -H "Content-Type: application/json" \
  -d '{"login":"admin","password":"admin123"}' | python -c "import sys,json;print(json.load(sys.stdin)['token'])")
curl -s "http://127.0.0.1:8000/api/conflicts" -H "Authorization: Bearer $TOKEN"
```
