## 0. 三条原则

| 要求 | 落地方式 |
|---|---|
| **方便 Agent 自主构建** | 每卡自包含：目标 / 独占文件 / 分支 / 前置 / 产出 / **可复制的验收命令** / 禁止事项。附录 A 给出全部领域层签名，**禁止为确认签名重读 `src/scheduler/`** |
| **减少人工核查** | CP 从 10 次降到 **3 次人工**（CP-D / CP-F / CP-H）；其余 7 次全部转成自动断言，跑绿即算通过 |
| **略微降 Credits** | 只靠流程硬约束（禁重读、单卡单文件、先针对性测试、重试上限 2），**不降模型档位**；目标 ≈302 万 → 220–240 万 |
