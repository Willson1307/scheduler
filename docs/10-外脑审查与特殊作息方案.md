### 先修正对夏冬风险的判断（队长补充：节次相同，只是大课间位置移动）

### 四类场景与现状

| 场景 | 现状 | 缺口 |
|---|---|---|
| 节假日停课 | ✅ `calendar_exceptions.kind='holiday'` **已生效** | 无 |
| 运动会 / 考试占用节次 | ✅ 用一次性日程占满当天 → 冲突检测 + 一键消解（**这正是核心卖点**） | 无 |
| **调休补课**（周末按周X课表上课） | ❌ `makeup` 定义了但代码没用，且无 `as_of_dow` 字段 | 需实现 |
| **换季 / 考试周**（节次结构或时刻不同） | ❌ 只有一套 `period_slots`，无日期维度 | 需 slot set |

### 方案：三张新表（纯追加，不动任何现有表）

```sql
-- 1) 作息方案
CREATE TABLE slot_sets (
    id         TEXT PRIMARY KEY,
    org_id     TEXT NOT NULL,
    name       TEXT NOT NULL,          -- 夏季 / 冬季 / 考试周 / 运动会
    is_default INTEGER NOT NULL DEFAULT 0
);

-- 2) 该作息的具体节次
CREATE TABLE slot_set_periods (
    set_id      TEXT NOT NULL REFERENCES slot_sets(id) ON DELETE CASCADE,
    day_of_week INTEGER NOT NULL,
    idx         INTEGER NOT NULL,
    name        TEXT, start_time TEXT NOT NULL, end_time TEXT NOT NULL,
    enabled     INTEGER NOT NULL DEFAULT 1,
    PRIMARY KEY (set_id, day_of_week, idx)
);

-- 3) 日期区间 → 用哪套作息（队长已定：手动设置，自动判定留二期）
CREATE TABLE slot_set_schedule (
    id        TEXT PRIMARY KEY,
    org_id    TEXT NOT NULL,
    from_date TEXT NOT NULL,
    to_date   TEXT NOT NULL,
    set_id    TEXT NOT NULL REFERENCES slot_sets(id)
);

-- 4) 例外日扩展（补 as_of_dow，不动旧 calendar_exceptions）
CREATE TABLE calendar_exceptions_ext (
    org_id    TEXT NOT NULL,
    date      TEXT NOT NULL,
    kind      TEXT NOT NULL,           -- holiday / makeup / special
    as_of_dow INTEGER,                 -- makeup：按周几的课表（1-7）
    set_id    TEXT,                    -- special：用哪套作息
    note      TEXT,
    PRIMARY KEY (org_id, date)
);
```

**代价**：`load_slot_config(conn, org_id)` 需增加 `on_date` 参数按天选配置 → 改 `slots.py`，属领域层红线 → 需走 E2 流程 + 队长批准 + 31 项老测试全绿。

**位图仍然零影响** —— 这是本设计的最大优势：换作息只改"时刻↔格子"的映射层，不动任何已存掩码。

| **MVP** | 节假日（已有）+ 运动会/考试用 once 表达（已有）+ 夏冬用**手动改 `period_slots` 时刻**（零改动，节次相同风险可控） | 10/7 前 |
