# 31 · Copilot 换手审查提示词（CP-H 复查用）

> **这份文件解决什么**：把「我们已经实测发现什么」和「还要你查什么」一次性交到审查方手上，
> 避免它从零重跑、也避免它把「我们以为的」当成结论。
>
>🔴 **铁律**：本项目最关注的问题类型是**静默失效**——不报错但给错误结果。已确认 13 处。
> 审查方**不得**给「看起来没问题」这类结论：要么给 `文件:行号` 证据，要么写明
>「需谁实跑什么才能确认」，交回给实现方。
>
> **用法**：复制下面代码块 → 新对话 → 粘贴。
> ⚠️ 这与「实现」必须**分对话**（审查分离：一卡一对话、审查方 ≠ 实现方）。

## 一、执行环境选择（先定这个，别开工了再想）

审查要读的文件量 ≈ 200–300k tokens，且**必须自己实跑命令验证**，不能只读代码。

### 1.1 本地 / 云 / Copilot 三选一

| 选项 | 判断 | 理由 |
|---|---|---|
| **本地**（qwen2.5-coder:3b） | ⛔ 不用 | 3b 编码弱、上下文装不下三份项目文档，红线约束会漏 |
| **云**（GLM / DeepSeek 等） | ⛔ 不用 | Space Bunny 在云里跑 = **自己审查自己发现的东西**。AGENTS.md 铁律「实现者不得审查自己的实现」 |
| **Copilot** | ✅ **用这个** | AGENTS.md 已定：**安全审查归 Copilot**；Space Bunny 是发现者不是审查方 |

### 1.2 Agent / Ask 二选一

| 模式 | 判断 | 理由 |
|---|---|---|
| **Ask** | ⛔ 不用 | 只能读文件。**审查必须能实跑命令**（见 §2 强制实跑清单），Ask 做不到 |
| **Agent** | ✅ **用这个** | 能执行 `doctor.py` / `smoke.py` / `probe_screenshots.py`，能自己验真伪而非推给队长 |

> 🔴 **为什么「必须能实跑」是硬要求**（不是建议）：
> 本项目 13 处静默失效中，P0-1（`rebuild_closure` 清空整张闭包表）、
> P0-2（调休 `makeup` 未实现）、第 12 处（`ASSET_VERSION` 漂移）
> **都是读代码看不出异常、只有实跑才暴露**的。
> 更早的教训更直接：契约测试曾长期输出 `Ran 0 tests` + `OK` + 退出码 0——
> 「绿灯」本身就需要被实测证伪，不能采信。

> ⚠️ **勘误（2026-10-11）**：本文件早期版本写着「Copilot 唯一做不到的是实跑」。
> 该说法源自队长 10/05 的口述，**从未实测**，且已确认不成立——
> Copilot 在本环境**可以执行命令**。故上文已删除该约束，改为「你必须自己实跑」。
