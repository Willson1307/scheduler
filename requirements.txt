# 本仓库【零第三方依赖】，只用 Python 标准库。
#
# 技术栈决定（已定稿，不要再改）：
#   - HTTP 层：Python 标准库 http.server（ThreadingHTTPServer），不引 FastAPI / Flask

#   3. 零第三方依赖 = 零供应链攻击面（答辩可正面讲）
